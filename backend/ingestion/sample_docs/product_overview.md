## What is LensPilot

LensPilot is a software platform that helps teams manage their workflows
and get insights from their data. It offers a web dashboard, a REST API,
and integrations with common business tools.

## Core Features

- Workflow automation: create rules that trigger actions automatically.
- Analytics dashboard: visualize key metrics in real time.
- Team collaboration: shared workspaces, comments, and task assignment.
- Integrations: connects with common tools via API and webhooks.

## Who it's for

LensPilot is built for small and mid-sized teams that need a single place
to manage their operations without stitching together many separate tools.

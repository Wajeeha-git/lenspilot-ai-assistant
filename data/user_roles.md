# User Roles

## Admin
Can:
- Manage shopkeepers
- Manage subscriptions
- Manage contact lens catalogue
- Monitor analytics
- Configure system settings
- Generate reports

## Shopkeeper
Can:
- Register account
- Login
- Subscribe to plans
- View dashboard
- View analytics
- Receive unique QR Code
- Display QR code inside shop
- Monitor customer try-ons

## Customer
Can:
- Scan QR code
- Open virtual try-on
- Choose contact lenses
- Allow camera access
- Try lenses in real time

Note: Customers do not need an account.
